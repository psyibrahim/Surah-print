# خطة إعادة هيكلة التحليل القرآني: الواجهة المبسطة والتحليل الوصفي الأكاديمي

خطة عمل متكاملة لتحويل التطبيق من حالة التعقيد الرياضي الكثيف إلى تجربة واضحة وأكاديمية سهلة الفهم، عبر تبني الإحصاء الوصفي البسيط (أطوال الآيات، تردد المفردات، والكلمات الفريدة) وتقديم نمطين للعرض: «النمط المبسط المباشر» و«نمط المختبر المتقدم».

---

## مراجعة المستخدم والقرارات الحاسمة (User Review & Critical Decisions)

> [!IMPORTANT]
> تم استطلاع رأي المستخدم وتأكيد التفضيلات المحورية التالية قبل الشروع في التنفيذ البرمجي:

- **المنهجية المعتمدة المؤكدة**: التركيز على **التحليل الإحصائي الوصفي البسيط للمفردات وأطوال الآيات**، باعتباره المنهج الأكاديمي الأوضح غير المعتمد على رياضيات معقدة أو افتراضات غير بديهية.
- **هيكلية التصفح المؤكدة**: توفير **واجهتين متكاملتين (تبديل بنقرة واحدة في الشريط العلوي)**:
  1. **الواجهة المبسطة (Simple / Essential Mode)**: تفتح افتراضياً، وتقدم إحصاءات وصفية مباشرة بأرقام حقيقية دون شتات أو مخططات مركبة.
  2. **الواجهة المتقدمة (Advanced Lab Mode)**: تحتفظ بأدوات المختبر للمتخصصين (مقارنات الحواميم، الرادار الصوتي، مصفوفات التباعد، وتشتت النسبة الذهبية).

---

## 1. النظرة العامة والمفهوم الأساسي (Overview & Core Concept)

### المشكلة التي نحلها
التطبيق حالياً يضم حسابات رياضية متقدمة (مثل تباعد كولباك-ليبلر، مصفوفات سبيرمان، وتحليلات التشتت)، مما جعل المستخدم يشعر بالتعقيد وصعوبة استخلاص الفائدة المباشرة. القرآن الكريم نص معجز ومترابط، وتظهر بلاغته وإعجازه العددي بأبسط العمليات الحسابية المباشرة (العد، المتوسطات، التكرار، والنسب المئوية) دون حاجة للتعقيد المصطنع.

### المنهجية الأكاديمية البسيطة المقترحة
سنعتمد على **الإحصاء الوصفي النصي (Textual Descriptive Statistics)**، وهو المنهج المعتمد في اللغويات الحاسوبية ودراسات النص القرآني، ويشمل:

1. **تحليل أطوال الآيات (Verse Length Metrics)**:
   - متوسط عدد الكلمات بالآية في كل سورة (قوة الإيقاع وسرعة السرد).
   - الآية الأطول والأقصر في السورة بنصها وعدد كلماتها.
   - توزيع الآيات (قصيرة جداً $\le 5$ كلمات، متوسطة 6-15، طويلة $\ge 16$).

2. **تحليل المفردات والقاموس القرآني (Vocabulary & Lexical Density)**:
   - نسبة التنوع المعجمي المباشرة: $\text{TTR} = \frac{\text{الكلمات الفريدة}}{\text{إجمالي الكلمات}} \times 100\%$.
   - الكلمات الحصرية (Hapax Legomena): الكلمات التي وردت مرة واحدة فقط في السورة وموقعها.
   - الكلمات الأكثر تكراراً بالسورة (مع استبعاد أو تمييز حروف المعاني والأدوات لبيان المحاور الموضوعية).

3. **إحصاء بنية السورة الحسابي**:
   - إجمالي الآيات والكلمات والحروف بوضوح تام وتنسيق رقمي عربي مجدول.
   - النصف الأول للسورة مقابل النصف الثاني (التناظر البسيط في حجم الآيات).

## 2. تجربة المستخدم والتصميم البصري (UX & Visual Design)

### مفتاح التبديل المركزي (View Mode Switcher)
في شريط التنقل العلوي، يُضاف مفتاح تبديل واضح ومرئي:
- `الوضع المبسط (الأساسي)`: واجهة هادئة، بطاقات رقمية واضحة، جداول مرتبة، ومخططات أعمدة بديهية ومباشرة.
- `مختبر التحليل المتقدم`: يفتح جميع الأقسام الرياضية التخصصية الحالية دون أي فقدان للميزات لمن يحتاجها.

### لوحة التحكم المبسطة (Simple Dashboard Architecture)
تتكون الواجهة المبسطة من 4 أقسام رئيسية واضحة:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. شريط الاختيار السريع للسورة (معلومات أساسية: مكية/مدنية · الآيات · الكلمات) │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2. بطاقات المؤشرات الوصفية الكبرى (Metric Kicker Cards):                    │
│    [متوسط طول الآية]   [نسبة التنوع المعجمي]   [الكلمات الفريدة]   [إجمالي الحروف]  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 3. نافذة المقارنة البسيطة لأطوال الآيات (أطول آية وأقصر آية مع النص الكامل)   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 4. قاموس السورة: الكلمات الأكثر شيوعاً والكلمات الحصرية ذات الورود الواحد      │
└─────────────────────────────────────────────────────────────────────────────┘
```

### المبادئ التصميمية (Design Discipline)
- **صفر تعقيد (Zero-Slop & Clean Numbers)**: إلغاء المصطلحات الهندسية المعقدة في الوضع المبسط واستبدالها بلغة عربية فصيحة ومألوفة للجميع.
- **أرقام مجدولة (Tabular Figures)**: جميع الأرقام تُعرض بوضوح بالخط المجدول المناسب لمنع التداخل.
- **بطاقات ذات ارتفاع موحد**: استخدام حدود رقيقة (Hairline borders) وخلفيات محايدة هادئة في الوضعين النهاري والليلي.
- **انعدام التداخل**: كل رقم أو كلمة لها مساحتها المريحة وتدرجها الواضح.

## 3. القرارات التقنية والمفاضلات (Key Product Decisions & Trade-Offs)

### القرار 1: نظام النمطين (Dual-Mode Architecture)
- **الخيار المعتمد**: توفير نمط مبسط افتراضي مع الاحتفاظ بنمط المختبر كخيار.
- **السبب**: يمنح المستخدم الجديد والباحث العادي وصولاً سريعاً ومفهوماً للحقائق القرآنية بنسبة 100% دون أن يُحرم الباحث المتخصص من الأدوات الرياضية المتقدمة التي تم بناؤها بالفعل.
- **البديل المرفوض**: مسح أو حذف التحليلات المتقدمة نهائياً، لأن ذلك يُفقد التطبيق قدراته العميقة التي قد يحتاجها بعض المستخدمين المتخصصين.

### القرار 2: توحيد معادلات التنوع المعجمي
- **الخيار المعتمد**: اعتماد النسبة المئوية المباشرة الصريحة $TTR = (\text{Unique Words} / \text{Total Words}) \times 100\%$ مع توضيح معناها بنص صريح: «من كل 100 كلمة في السورة، هناك X كلمة مختلفة غير مكررة».
- **السبب**: المعادلات الرياضية اللوغاريتمية (مثل Guiraud Index أو Maas Index) غامضة لغير المتخصصين، بينما النسبة المئوية البسيطة مفهومة فوراً لكل قارئ.

## 4. البنية التقنية ومسار البيانات (Technical Architecture)

### مخطط تدفق الواجهة وحالة العرض

```
                    ┌───────────────────────────┐
                    │      Top Bar Header       │
                    │  [Simple] ⇄ [Advanced]    │
                    └─────────────┬─────────────┘
                                  │
         ┌────────────────────────┴────────────────────────┐
         ▼                                                 ▼
┌─────────────────────────┐                     ┌─────────────────────────┐
│       Simple Mode       │                     │    Advanced Lab Mode    │
│  (Descriptive Focus)    │                     │   (Full Instrumentation) │
├─────────────────────────┤                     ├─────────────────────────┤
│ • SimpleSurahOverview   │                     │ • LettersLab & Radar    │
│ • SimpleVerseLengthCard │                     │ • LexicalRichnessLab    │
│ • SimpleVocabFrequency  │                     │ • HawameemComparative   │
│ • SimpleSurahComparison │                     │ • MathematicalMetrics   │
└─────────────────────────┘                     └─────────────────────────┘
```

### المكونات الجديدة المقترحة للوضع المبسط:
1. `src/components/SimpleQuranDashboard.tsx`: الحاوية الرئيسية للوضع المبسط، تربط السورة المختارة بالتحليلات الثلاثة السهلة.
2. `src/components/SimpleVerseLengthCard.tsx`: عرض معدل طول الآيات، أطول آية، أقصر آية، ومخطط أعمدة أفقي مبسط جداً بدون شبكات معقدة.
3. `src/components/SimpleVocabularyCard.tsx`: عرض قائمة الكلمات الأكثر تكراراً بصيغة بطاقات/أعمدة سهلة، مع الكلمات الفريدة التي تميز السورة.
4. `src/components/SimpleSurahCompare.tsx`: مقارنة سورتين وجهاً لوجه في 4 أرقام واضحة (الآيات، الكلمات، متوسط الطول، التنوع).
